## Reglas generales del Código
- Solo JavaScript puro: la entrada se hace con `prompt()` y la salida con `alert()`. No se usará DOM ni librerías. *NOTA: Por favor abstenerse de usar console.log para mostrar los salidas de datos, únicamente úselo para depurar y corregir el código.*
- No se permite el uso de arreglos (arrays) ni objetos. Solo variables, constantes, operadores y estructuras de control (`do`, `do while`, `if`, `else if`, `else`, `for`, operador ternario) y `function`.
- Todo dato leído con `prompt()` es un `String` por defecto, debe convertirlo a número cuando corresponda.
- Los valores monetarios (SMMLV, UVT, SMDLV, tasas, etc.) son **didácticos**: se redondearon para facilitar los cálculos y deben tratarse como constantes del enunciado, aunque no coincidan con las cifras oficiales vigentes para el año 2026.
- En las tablas de casos de prueba se usa el punto para miles y decimales, recuerde que no se permiten ingresos de cifras con puntos o comas para miles.
- Los valores en pesos se muestran sin símbolo `$`.
- Los casos de prueba cubren todas las combinaciones de ramas de decisión de cada problema, incluidos los valores límite y las entradas inválidas.
